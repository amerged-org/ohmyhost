# Security reports

Send a private report through [ohmyho.st/contact](https://ohmyho.st/contact), identifying it as a security report. If this repository offers GitHub private vulnerability reporting, you can use that channel too. Please avoid disclosing an unresolved vulnerability in a public issue or pull request.

Include the affected revision or client version, impact, reproduction steps and minimal sanitized evidence. Remove credentials, authentication tokens, personal information and customer data. Do not access another customer's resources to demonstrate impact.

A vulnerability report alone is not a Contribution under [LICENSE, Appendix I — Contributing](LICENSE#L96). If you intentionally submit a patch for inclusion through a private security advisory, the appendix applies to that patch. You retain ownership; no separate signature or contribution checkbox is required.

We make no response-time, remediation-time or bounty commitment in this policy.
