# Source and release status

The [architecture](docs/architecture/index.md) represents the current source.
The [public docs](https://docs.ohmyho.st/) describe supported hosted behavior.

Changes to customer surfaces keep the SDK, CLI, local and remote MCP, Skills
and the public docs in sync. Release verification records the exact source
repository and commit.

## Historical decisions

The decision register identifies retired provider integrations, previous
verification policy and superseded product designs. Those entries document
the design lineage. Original implementation snapshots and operational
evidence are maintained with archived releases.

## Future work

Deferred telemetry integration and acceptance work is tracked as design
intent. Configurable export destinations belong to a separate capability
beyond the SQL archive download endpoint. Consult the current public docs
for supported hosted behavior.
