## D603 — Private Core feedback operator

| ID   | State                                 | Decision                                                                    | Code or current boundary                                                                                                                                                                        |
| ---- | ------------------------------------- | --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D603 | Released; scoped application verified | Private exact-receipt feedback preview and atomic append, audit and replay. | [apps/control-store/src/catalog/public-entry/feedback-operator.ts:157](https://github.com/amerged-org/ohmyhost/blob/main/apps/control-store/src/catalog/public-entry/feedback-operator.ts#L157) |

Released in 0.1.57; customer-visible feedback status changes require separate reviewed application and readback. A dedicated private `FeedbackOperatorRuntime` restores the operator append capability removed with the PostgreSQL Control. It exposes only preview/apply for one validated receipt, never SQL or a public management route. The operator verifies the chosen Cloudflare account/Core/environment and current human session; the Core records the exact customer-visible status event, audit and replay result atomically under a stable event/command identity. Exact prior status and latest event fence concurrent writes, including intervening internal notes. An uncertain answer is observed under the same receipt/event, and an exact reviewed replay retains its original command identity. Source replies reject control characters and unpaired Unicode surrogates; valid Unicode text is preserved. Release evidence.

`resolved` requires the named shipped release and a meaningful customer explanation; `closed` explains why no further change follows. The original report, existing events and customer authorization/read policy remain unchanged. This supersedes D345's W33 "no writer" qualification only; it does not turn code or a receipt into a live fix. [Operator source](../../../scripts/feedback-operator.mjs), [Core command](../../../apps/control-store/src/catalog/public-entry/feedback-operator.ts), W47.

The scoped W47 application completed with nine resolved and 24 planned events, all privately read back; 21 owning-workspace public histories were additionally checked. Twelve foreign-workspace readbacks are private-only, and one unread-history report was untouched. The internal client now materializes the already validated primitive acknowledgement before proxy disposal; a failing/passing regression and an actual cached acknowledgement qualify that correction without changing the deployed Core or creating another event. Tooling evidence.
