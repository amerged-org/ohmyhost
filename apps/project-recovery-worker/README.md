# project-recovery-worker

Trusted Node SQL-export executor packaged into the Cloudflare recovery Container. Customer exports are request-only password-encrypted SQL ZIP files.

The current implementation, scope, failure semantics and acceptance boundaries are documented in [the canonical architecture chapter](../../docs/architecture/mail-and-recovery.md). Historical module prose is retained under `docs/plan/history/module-readmes/`; it is not a second current contract.
