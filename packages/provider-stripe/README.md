# provider-stripe

Private Stripe provider adapter for paid invoices, top-ups, recharge and payment reversals. Confirmed provider evidence, not browser redirects, authorizes ledger changes.

See [the current architecture chapter](../../docs/architecture/billing-and-pricing.md) for contracts, trust boundaries, credentials, lifecycle and verification limits. Previous module prose is retained in `docs/plan/history/module-readmes/` as historical context.
